# .github

Organization-wide defaults for `globaltronic-intertrade`. Repositories that have no
`.github/ISSUE_TEMPLATE/` folder of their own use the issue forms here:

| Form           | Use for                                                |
| -------------- | ------------------------------------------------------ |
| Task           | One piece of work                                      |
| Bug            | Something works wrong, including issues after handover |
| On-site        | Site survey, installation or maintenance visit         |
| Change Request | A customer asks to change the signed-off scope         |

New issues are added to the team board automatically. Keep passwords, internal IP addresses and
customer contact details out of issues.
